## 五、附：素材怎么重生成（自用备忘）

| 用途 | 地址 |
| --- | --- |
| 完整演示台（17 场景） | `index.html` |
| 外发单场景页（含免责与出处占位） | `index.html?sc=sleepless&press=1` |
| 只留画面，出封面/录屏 | `index.html?sc=sleepless&press=2` |
| 定格某一阶段（**1–6**，自动暂停推进） | `…&stage=3` |
| 调整画面大小（0.5–2.4，默认 1） | `…&z=1.5` |
| 换场景 | `?sc=` 换成 17 个 key 之一：`dependence withdrawal craving doomscroll flow habit procrastinate fatigue compulsion heartbreak rejection attachment revenge stress panic flashback sleepless` |

**本次交付用的取景**：头图 `stage=3&z=1.5` / 竖版 `stage=2&z=2.1` / 方形 `stage=5&z=2.1` / 定格帧 `stage=1…6&z=1.3`。
`press=2` 会自动隐掉两侧信息栏，只在左上留「场景号 + 阶段名 + 时间窗」、左下留系列与免责字样，所以出图不用再裁。

**无头截图配方**（一条命令一张图，别批量跑，容易堆成十几个僵死 chrome 进程把机器拖没）：

```
chrome --headless=old --disable-gpu --hide-scrollbars \
  --user-data-dir=<独立临时目录> \
  --window-size=1280,720 --virtual-time-budget=2000 \
  --run-all-compositor-stages-before-draw \
  --screenshot=<绝对路径.png> \
  "http://127.0.0.1:5200/index.html?sc=sleepless&press=2&stage=3&z=1.3"
```

`--virtual-time-budget` 要按画幅调：900×500 / 1280×720 用 2000–4000 稳；**1080×1080 与 1080×1920 用 9000 会挂死**，降到 1200–4000 才出得来。

成品图与关键帧在 `press/images/`（head / poster / square + frame-01…06）。
